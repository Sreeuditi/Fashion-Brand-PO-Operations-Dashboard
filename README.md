# Fashion Brand Purchase Order & Operations Dashboard

1. Project Overview:
This project is a simulated e-commerce operations workflow built using Microsoft Excel.
The project focuses on purchase order management, inventory monitoring, PO tracking, TAT monitoring, operational issue tracking and dashboard-based reporting.
The project was created as a practical exercise to understand how Excel can be used for data analysis and day-to-day business operations.

2. Objectives:
~ Maintain structured product and brand master data.
~ Monitor inventory levels and re-order requirements.
~ Create and track purchase orders.
~ Monitor PO delivery status and TAT exceptions.
~ Analyse operational data using PivotTables.
~ Build an Excel dashboard for quick business insights.

3. Tools and Skills:
i. Microsoft Excel
ii. Excel Tables and Formulas
iii. Conditional Formatting
iv. PivotTables
v. Charts and Visualisation
vi. Inventory Tracking 
vii. PO Tracking
viii. TAT Monitoring 
ix. Issue Tracking

4. Operational Workflow:
Product and Brand Master ➡ Inventory Monitoring ➡ Re-order Identification ➡ PO Creation ➡ PO Tracking ➡ TAT Monitoring ➡ Issue Identification ➡ Issue Resolution ➡ Dashboard Reporting 

5. Operational Scenarios Practiced:
The project includes simulated operational exceptions such as-
i. Delivery delays
ii. Pending PO confirmation
iii. Quantity matching 
iv. Incorrect SKU
v. Delivery tracking issues

These scenarios were used to practice issue identification, stakeholder follow-up and exception tracking.

6. Learning Outcome:
Through this project, I practiced using Microsoft Excel not only for calculations, but also for organising operational data, identifying exceptions, tracking order performance and presenting information through a business dashboard.

⚠️ Disclaimer: This is a simulated portfolio project created for learning and demonstration purposes. The purchase orders, brands, products and operational scenarios used in the workbook are fictional.
